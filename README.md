# محرك القرآن السينمائي — Quran Launcher

هذا المستودع نسخة مستقلة لاختبار نقل محرك الفيديو الأصلي إلى Quran Launcher. العمل الحالي يتم على الفرع `feature/islamic-tiktok-engine-port` فقط.

## ما يعمل فعليًا الآن

- تشغيل محرك Python وFFmpeg داخل GitHub Actions، وليس تسجيل فيديو داخل المتصفح.
- إنشاء فيديو مراجعة عمودي MP4 بمقاس 1080×1920 و30 إطارًا/ثانية.
- بناء فهرس كامل من 6,236 آية: النص العثماني + ترجمة Saheeh International + فهرس تلاوة ماهر المعيقلي برواية حفص. هذه بيانات مرشحة للمراجعة وليست اعتمادًا تلقائيًا للنشر.
- اختيار خلفية فيديو متحركة من الأصول التي اجتازت بوابة الاعتماد، مع تدوير الاختيار.
- تجهيز 3 فيديوهات مراجعة مرشحة من مكتبة القرآن الكاملة (114 سورة و6,236 آية). يختار النظام مقاطع متنوعة من سور مختلفة، ولا يعني ذلك أن المكتبة تقتصر على ثلاث سور. كل مقطع يحافظ على الآيات كاملة ومن دون إضافة صمت بين الآيات.
- حد أقصى 40 ثانية للفيديو والمقطع الصوتي؛ لا تُقسّم الآية لتلائم المدة.
- حفظ الناتج كـ GitHub Actions Artifact للمراجعة والتنزيل؛ لا يوجد نشر تلقائي.

## تشغيل المحرك من واجهة Launcher

- زر **تشغيل 3 فيديوهات الآن** يرسل طلب `workflow_dispatch` مباشرة إلى GitHub Actions على الفرع المعزول.
- يلزم Fine-grained Personal Access Token محدد لهذا المستودع فقط مع صلاحية **Actions: Read and write**. لا تستخدم رمزًا عامًا أو صلاحيات أوسع.
- يُستخدم الرمز في ذاكرة الصفحة لإرسال الطلب فقط، ولا يُحفظ في `localStorage` أو ملفات المستودع، ويُمسح من الحقل بعد الإرسال.
- بعد قبول الطلب، تتابع الواجهة حالة التشغيل وتعرض رابط تفاصيل التشغيل وحزمة Artifacts.
- لا يمكن للصفحة العامة تشغيل GitHub Actions دون تفويض من صاحب المستودع؛ لذلك لا يوجد رمز ثابت داخل التطبيق.

## طريقة الاختبار الحالية

1. افتح [سير عمل إنشاء الفيديو](https://github.com/samiouess-ux/quran-launcher/actions/workflows/quran-launcher-engine-render.yml).
2. اختر **Run workflow** ثم أكّد التشغيل.
3. بعد نجاح التشغيل، افتح نتيجة التشغيل ونزّل Artifact باسم `quran-launcher-full-quran-review`.

هذه خطوات يدوية عبر GitHub؛ صفحة GitHub Pages لا تحتوي على رمز GitHub ولا تستطيع تشغيل Workflow موثّقًا مباشرةً بأمان.

## ما لم يكتمل بعد

- ربط عناصر الواجهة باختيار السورة والآيات والقارئ والخلفية، وإضافة واجهة آمنة لبدء التشغيل من داخل التطبيق دون كشف أسرار GitHub.
- إكمال مراجعة واعتماد النص والترجمة والتسجيل والخلفية وحقوق إعادة الاستخدام قبل أي نشر.
- ربط تسليم ملفات المراجعة بوسيلة التسليم التي يحددها المستخدم؛ سير العمل الحالي يحفظ Artifact فقط.

## ضوابط ثابتة

- العربية القرآنية مع ترجمة Saheeh International الإنجليزية فقط.
- لا موسيقى؛ تلاوة قرآنية فقط.
- لا اقتطاع للآيات؛ اختيار آيات كاملة متتابعة.
- حد أقصى 40 ثانية للفيديو والصوت، من دون فرض مدة دنيا، مع الحفاظ على الآيات كاملة.
- لا نشر تلقائي على TikTok؛ مراجعة المستخدم مطلوبة.
- لا تعديل للمستودع الأصلي `IslamicTikTokAutomation` أو فرع `main`.
- لا تعديل لبوت Telegram أو المجدول أو إعدادات GitHub Pages ضمن هذا العمل.

## ملاحظة عن الواجهة

شكل الواجهة الحالية محفوظ كما هو. وهي تفتح سير عمل GitHub يدويًا؛ لا ينبغي اعتبارها بعدُ واجهة تحكم كاملة بالمحرك.
