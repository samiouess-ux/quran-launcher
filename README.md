# محرك فيديوهات القرآن الكريم — الإصدار الثاني

مشروع مستقل تماماً عن المحرك القديم.

## ما يعمل الآن
- إدخال عنوان السورة ونص الآيات واسم القارئ.
- اختيار ملف تلاوة صوتية من الهاتف.
- اختيار صورة خلفية أو استعمال خلفية افتراضية.
- معاينة تصميم الفيديو بنسبة 16:9.
- تسجيل الفيديو داخل المتصفح بصيغة WebM مع صوت التلاوة.
- تنزيل الملف الناتج مباشرة دون رفع الملفات إلى خادم.

## التشغيل
افتح \`index.html\` عبر استضافة صفحات ثابتة (مثل GitHub Pages) أو خادم محلي حديث. يلزم متصفح يدعم Canvas captureStream وMediaRecorder وWeb Audio API. يفضّل Chrome أو Safari محدّث.

## حدود النسخة الحالية
النص يظهر ككتلة واحدة طوال مدة التلاوة. لا يوجد بعد تقسيم آلي للآيات أو مزامنة توقيت كل آية أو قوالب متعددة. صيغة التصدير الحالية WebM.

## الاستقلال
لا توجد تبعيات على ملفات المحرك القديم، ولا تعدّل هذه النسخة ذلك المشروع.
