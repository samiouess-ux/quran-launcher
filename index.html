فتح المحرك وتشغيل إنشاء الفيديو

بعد فتح GitHub: اضغط Run workflow ثم Run workflow. عند اكتمال التشغيل ستجد حزمة الفيديوهات الثلاثة وملفات المراجعة في Artifacts باسم quran-launcher-three-surah-review.

ما الذي يحدث عند التشغيل؟

  • تشغيل محرك Python وFFmpeg الحقيقي، وليس مسجل Canvas القديم.
  • اختيار عدة خلفيات فيديو متحركة من المكتبة المعتمدة ودمجها بانتقالات ناعمة.
  • إظهار الآيات بالعربية والترجمة الإنجليزية مع التلاوة، مع إبقاء إطار الآيات ثابتًا عند الانتقال.
  • فحص ملف MP4 ثم حفظه كملف مراجعة قابل للتنزيل.
